# Road Accident Analysis Dashboard

## Overview

An interactive Tableau dashboard analyzing road accident data to identify accident severity patterns, major causes, vehicle involvement, driver demographics, weather impact, and hourly accident trends.

## Dashboard Features

* KPI Cards for Total Accidents, Casualties, Vehicles Involved, and Fatal Accidents
* Accident Severity Analysis
* Leading Causes of Accidents
* Hourly Accident Trend
* Vehicle Involvement Analysis
* Driver Age Group Analysis
* Weather Conditions Impact
* Interactive Dashboard Filtering

## Tools & Technologies

* Tableau Public
* Python
* Pandas
* Excel

## Key Metrics

* Total Accidents: 12,316
* Total Casualties: 19,067
* Fatal Accidents: 158
